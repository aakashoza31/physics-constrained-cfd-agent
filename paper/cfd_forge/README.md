# CFD Forge conference paper (working draft)

- `main.tex`: manuscript (Overleaf source of 2026-09-30, extended with Results, Limitations and Conclusion). Build: `latexmk -pdf main.tex`.
- `figures/`: Figures 2–5, generated by `python3 scripts/make_figures.py` (needs numpy and matplotlib).
- `data/`: verbatim copies of the archived evidence the figures read; `data/DATA_MANIFEST.json` lists the source path and SHA-256 of each.
- `EVIDENCE_MAP.md`: every numerical claim, with its source file and key.
- `PAPER_GAPS.md`: open items and TODOs.

The Overleaf project itself has not been modified.
