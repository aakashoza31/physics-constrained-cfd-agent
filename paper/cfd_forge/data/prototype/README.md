# Prototype run records

Archived records of the earlier CAD->Gmsh prototype run
(`runs/20260914_020146_conical_nozzle`), which the paper describes as the
predecessor of the registered nozzle path. They are not part of the CFD Forge
registered path. The files are kept unchanged (their SHA-256 values are in
`../DATA_MANIFEST.json`); the images that `CFD_REPORT.md` references were not
released.
